El login es el proceso que permite identificar a un usuario antes de ingresar a una aplicación. Gracias a la autenticación, solo las personas autorizadas pueden acceder a determinadas funciones o información. Algunas rutas deben estar protegidas porque contienen datos privados o permiten realizar acciones importantes dentro del sistema. No se deben exponer públicamente contraseñas, documentos de identidad, teléfonos, direcciones, claves de API ni otros datos sensibles. Esto ayuda a proteger la privacidad y la seguridad de los usuarios.
